# Работа №1: перестановка битов, сеть Фейстеля и DES

Реализация на C#/.NET 8 содержит пункт 1 (перестановка битов), необходимые интерфейсы из пункта 2, пункт 3 (сеть Фейстеля) и пункт 4 (DES). Готовые реализации шифров не используются.

Проверить каждый пункт можно одной командой из корня репозитория:

```bash
dotnet run --project lab_01/Demo/CryptoLab.Demo.csproj
```

Консольный пример проверяет перестановку битов, обратимость сети Фейстеля и известный вектор DES `0123456789ABCDEF → 85E813540F0AB405`, затем расшифровывает его обратно.
